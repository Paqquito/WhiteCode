name: promote-memory
description: "Review the layers of instructions and memories, and propose promotions, merges of duplicates, resolutions of contradictions and removals of obsolete entries. Use it when the user wants to organise what the agent remembers."
---
Review the memory of the agent. Its layers, from the most personal to the most shared:

{%MEMORY_LAYERS%}

1. Identify:
   - promotions: an entry of a personal layer that describes a convention of the repository, true for the whole team, belongs to the project instructions `{%INSTRUCTIONS_FILE%}`; a personal preference that applies to every project belongs to the user instructions;
   - duplicates, contradictions between layers, and entries that are obsolete given the current state of the repository.
2. Present the proposals as a list. Each one gives: the entry, the target layer, the reason, and the exact text proposed. When there is nothing to propose, say so.
3. Apply only the proposals the user accepts, with the ordinary writing tools. When an entry is promoted, remove it from its original layer so that it is not duplicated.
4. Before promoting anything to a shared layer, check that the text holds no secret (key, token, password, internal address); never promote one.
